MOVIE GENRE CLASSIFICATION PROJECT

1. Place your dataset files in this folder:
   - train_data.txt
   - test_data.txt
   - test_data_solution.txt
   - description.txt

2. Install requirements:
   pip install pandas scikit-learn flask

3. Train model:
   python train_model.py

4. Run app:
   python app.py

Open browser:
http://127.0.0.1:5000
